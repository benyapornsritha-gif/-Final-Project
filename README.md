# 📖 Novelnest - เว็บไซต์อ่านและแต่งนิยายออนไลน์

**Novelnest** เป็นเว็บแอปพลิเคชันสำหรับการอ่านและแต่งนิยายออนไลน์ ออกแบบด้วยดีไซน์ที่ทันสมัย (Modern Glassmorphic UI) รองรับการใช้งานทั้งบนคอมพิวเตอร์และอุปกรณ์เคลื่อนที่ (Responsive Design)

---

## 🌟 ฟีเจอร์หลัก (Key Features)

### 1. 🏠 หน้าแรก (Home Page - `index.html`)
- แบนเนอร์แนะนำนิยายเรื่องเด่นประจำสัปดาห์
- ส่วนแสดงนิยายยอดนิยม และนิยายอัปเดตใหม่
- แถบนำทาง (Navbar) ที่เชื่อมโยงไปยังทุกส่วนของเว็บไซต์ พร้อมระบบเข้าสู่ระบบแบบไดนามิก

### 2. 📚 ชั้นหนังสือ (Bookshelf - `books.html`)
- คลังรวบรวมหนังสือนิยายทั้งหมด สามารถคลิกเข้าไปอ่านเนื้อหาของแต่ละเรื่องได้ทันที
- แยกหมวดหมู่นิยายอย่างชัดเจน

### 3. ✍️ ระบบเขียนนิยายและเพิ่มตอน (Writing System - `write.html` & `add_chapter.html`)
- **สร้างเรื่องใหม่ (`write.html`):** ฟอร์มสำหรับนักเขียนในการเพิ่มนิยายใหม่ เลือกหมวดหมู่ ใส่เรื่องย่อ และอัปโหลดรูปปก
- **เพิ่มตอนนิยาย (`add_chapter.html`):** เครื่องมือสร้างและเพิ่มตอนใหม่ ใช้งานง่าย พร้อมบันทึกข้อมูลแบบ Dynamic ใน `localStorage`

### 4. 📖 ระบบอ่านนิยาย (Reading Interface - `read.html`)
- รองรับการอ่านเนื้อหาจริงที่ถูกเพิ่มจากนักเขียน
- มีระบบ **Predictable Content Generator (Hash Algorithm)** สำหรับสร้างเนื้อหาจำลองเฉพาะของแต่ละเรื่อง ป้องกันปัญหาเนื้อหาซ้ำกันระหว่างเรื่อง

### 5. 👤 ระบบโปรไฟล์นักเขียนและการแยกสิทธิ์ (Author Profile & Role System - `authors.html` & `login.html`)
- แสดงข้อมูลผู้แต่ง (นามปากกา, สถิตืองานเขียน, จำนวนคนอ่าน, จำนวนผู้ติดตาม)
- **ระบบแยกสิทธิ์ผู้ใช้งาน (Role-based UI):**
  - **นักเขียน (Writer):** สามารถมองเห็นปุ่ม "แต่งนิยาย" และปุ่ม "+ เพิ่มตอน" บนหนังสือนิยายทุกเรื่อง
  - **นักอ่าน (Reader) / ผู้เยี่ยมชม:** ระบบจะซ่อนปุ่มสำหรับการแต่งและแก้ไขนิยายโดยอัตโนมัติ

### 6. 💬 มุมพูดคุย (Discussion Corner - `discussion.html`)
- พื้นที่สำหรับนักอ่านและนักเขียนในการแลกเปลี่ยนความคิดเห็น ตั้งกระทู้ และพูดคุยกันเกี่ยวกับนิยาย

---

## 🔑 บัญชีผู้ใช้สำหรับทดสอบระบบ (Test Credentials)

คุณสามารถทดสอบเข้าสู่ระบบด้วยสิทธิ์ที่แตกต่างกันได้ที่หน้า **เข้าสู่ระบบ (`login.html`)**:

| สิทธิ์การใช้งาน (Role) | ชื่อผู้ใช้ (Username) | รหัสผ่าน (Password) | รายละเอียด |
| :--- | :--- | :--- | :--- |
| **นักเขียน (Writer)** | `Wt` | `1234` | แสดงรูปโปรไฟล์นักเขียน สิทธิ์สร้างนิยายและเพิ่มตอน |
| **นักอ่าน (Reader)** | `Rd` | `1122` | แสดงรูปโปรไฟล์นักอ่าน ซ่อนปุ่มแต่งนิยายและเพิ่มตอน |

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)

- **HTML5 & Semantic Elements:** โครงสร้างเว็บตามมาตรฐาน
- **CSS3 & Flexbox/Grid:** การจัดเลย์เอาต์ ออกแบบ UI แบบ Glassmorphism และ Responsive
- **JavaScript (ES6+):** การจัดการข้อมูลความสัมพันธ์, DOM Manipulation, LocalStorage API, และ Hashing Algorithm
- **Font Awesome 6:** ไอคอนประกอบเว็บไซต์
- **Google Fonts:** Sarabun Font Family

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
Novelnest_1/
├── assets/             # ไฟล์รูปภาพประกอบ รูปปกนิยาย และรูปโปรไฟล์
├── index.html          # หน้าแรกของเว็บไซต์

├── contact.html        # หน้าติดต่อเรา
├── login.html          # หน้าเข้าสู่ระบบ
├── write.html          # หน้าสร้างนิยายเรื่องใหม่
├── add_chapter.html    # หน้าเพิ่มตอนให้นิยาย
├── read.html           # หน้าสำหรับอ่านเนื้อหานิยาย
├── style.css           # สไตล์หลักของเว็บไซต์ (Global CSS)
└── README.md           # เอกสารอธิบายโปรเจกต์
```
