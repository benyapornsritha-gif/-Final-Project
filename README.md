# 📖 Novelnest - เว็บไซต์อ่านและแต่งนิยายออนไลน์

**Novelnest** คือแพลตฟอร์มเว็บไซต์อ่านและแต่งนิยายออนไลน์แบบครบวงจร ที่ถูกออกแบบมาเพื่อให้นักอ่านและนักเขียนสามารถแบ่งปันจินตนาการและเรื่องราวที่น่าสนใจได้อย่างสะดวก สวยงาม และใช้งานง่ายบนทุกอุปกรณ์

---

## 🌟 ฟีเจอร์หลักของระบบ (Key Features)

### 📚 1. ระบบคลังหนังสือและการอ่าน (Reading System)
* **การอ่านแบบไดนามิก (Dynamic Content Generation):** นิยายทุกเรื่องมีเนื้อหาที่เป็นเอกลักษณ์เฉพาะตัว ไม่ซ้ำกันในแต่ละเรื่อง
* **รองรับระบบตอน (Multi-Chapter Reading):** สามารถคลิกอ่านนิยายได้ทุกเรื่อง รองรับทั้งเนื้อหาตั้งต้น และเนื้อหาที่ถูกเพิ่มเข้ามาใหม่โดยนักเขียน

### ✍️ 2. ระบบแต่งนิยายและเพิ่มตอน (Authoring & Publishing System)
* **สร้างเรื่องใหม่ (`write.html`):** นักเขียนสามารถสร้างนิยายเรื่องใหม่ กำหนดชื่อเรื่อง นามปากกา หมวดหมู่ คำเกริ่น และเนื้อเรื่อง พร้อมระบบบันทึกลงใน `localStorage`
* **เพิ่มตอนใหม่ (`add_chapter.html`):** นักเขียนสามารถเพิ่มตอนให้นิยายเรื่องเดิมของตนเองได้ พร้อมเครื่องมือจัดรูปแบบข้อความ (Rich Text Tools: ตัวหนา, ตัวเอียง, จัดกึ่งกลาง ฯลฯ)

### 🔐 3. ระบบจำลองเข้าสู่ระบบตามสิทธิ์ผู้ใช้งาน (Role-Based Auth System)
รองรับการทดสอบสิทธิ์การใช้งานผ่านหน้า `login.html`:
* 🖊️ **สิทธิ์นักเขียน (Writer):**

  * สามารถมองเห็นปุ่ม **"แต่งนิยาย"** และปุ่ม **"+ เพิ่มตอน"** ในหน้าโปรไฟล์เพื่อจัดการผลงานได้
* 📖 **สิทธิ์นักอ่าน (Reader):**

  * แสดงรูปโปรไฟล์ผู้อ่านเฉพาะตัว (`ผู้อ่าน.jpg`) และระบบจะซ่อนปุ่มแต่งนิยาย/เพิ่มตอน เพื่อประสบการณ์การอ่านที่สบายตา

### 👤 4. หน้าโปรไฟล์นักเขียนและสถิติ (Author Profile & Stats)
* แสดงข้อมูลนักเขียน นามปากกา สถิติการอ่าน จำนวนผู้ติดตาม และยอดเพิ่มเข้าชั้น
* อัปเดตจำนวนเรื่องและจำนวนตอนแบบเรียลไทม์เมื่อมีการแต่งนิยายหรือเพิ่มตอนใหม่

### 💬 5. มุมพูดคุยและติดต่อสอบถาม (Community & Contact)
* **หน้ามุมพูดคุย (`discussion.html`):** กระดานข่าวสารและการแลกเปลี่ยนความคิดเห็นระหว่างนักอ่านและนักเขียน
* **หน้าติดต่อ (`contact.html`):** แบบฟอร์มส่งข้อความติดต่อทีมงาน

## 🛠️ เทคโนโลยีที่ใช้ (Technologies Used)

* **HTML5:** โครงสร้างเว็บแบบ Semantic HTML รองรับ SEO Best Practices
* **CSS3:** ออกแบบด้วย Vanilla CSS พร้อม Custom Properties (Variables), Responsive Grid/Flexbox Layout, Modern Glassmorphism และโทนสีตาม Design System
* **JavaScript (ES6+):** ควบคุมการทำงานเชิงโต้ตอบ (DOM Manipulation), ระบบ Auth จำลอง, และการจัดการข้อมูลด้วย Browser `localStorage`
* **Fonts & Icons:** Google Fonts (Sarabun) และ FontAwesome v6.4

## 🤖 การประยุกต์ใช้งาน AI ในการพัฒนาโปรเจกต์ (AI-Assisted Development)

โปรเจกต์นี้ได้รับการช่วยเหลือและร่วมพัฒนาโดยใช้เทคโนโลยี **AI Coding Assistant** ในด้านต่างๆ ดังนี้:

1. **🎨 การออกแบบและพัฒนาส่วนต่อประสานผู้ใช้ (UI/UX & Design System):**
   - ช่วยวางโครงสร้างและเขียนโค้ด HTML5/CSS3 ตามหลักการออกแบบทันสมัย (Modern Glassmorphic & Vibrant Styling)
   - จัดระเบียบการแสดงผลแบบ Responsive Web Design รองรับทั้งหน้าจอคอมพิวเตอร์และอุปกรณ์เคลื่อนที่

2. **⚡ การพัฒนาระบบสคริปต์และตรรกะการทำงาน (Logic & State Management):**
   - ออกแบบอัลกอริทึม **Predictable String Hashing** เพื่อสุ่มสร้างเนื้อหานิยายเฉพาะตัวที่ไม่ซ้ำกันในแต่ละเรื่อง (`read.html`)
   - พัฒนาระบบบันทึกและจัดการข้อมูลด้วย **Browser `localStorage`** สำหรับฟีเจอร์การแต่งนิยายและการเพิ่มตอน (`write.html`, `add_chapter.html`)
   - เขียนระบบจำลองการเข้าสู่ระบบแยกสิทธิ์ผู้ใช้ (**Role-Based Access Control**) สำหรับนักเขียน (`Wt`) และนักอ่าน (`Rd`) พร้อมเงื่อนไขการซ่อน/แสดงปุ่มควบคุมแบบอัตโนมัติ

3. **🔍 การวิเคราะห์ แก้ไขข้อผิดพลาด และจัดทำเอกสาร (Debugging & Documentation):**
   - ตรวจสอบและแก้ไขข้อผิดพลาดของสคริปต์ (Syntax Error & Execution Logic)
   - ช่วยจัดทำโครงสร้างเอกสารคู่มือการพัฒนาและการใช้งานระบบ (`README.md`)

4. **🚀 กระบวนการส่งมอบงานและการปรับใช้ (Version Control & Deployment):**
   - ช่วยดำเนินการจัดการ Git Repository และการ Push ขึ้น GitHub เพื่อเปิดใช้งานบน **GitHub Pages**

```text
Novelnest_1/
```
